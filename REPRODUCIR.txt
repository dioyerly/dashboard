RECONSTRUIR UN CLON NUEVO SIN SECRETOS NI EJECUTABLES
Windows x64, Python y PowerShell disponibles. Desde la raiz:
  powershell -File tools/restore_portable_runtime.ps1
Descarga distribuciones oficiales y verifica los SHA-256 fijados en
preparation/runtime-distributions.json antes de extraer. Rechaza reemplazar
runtimes existentes. No instala servicios ni cambia PATH. Si el distribuidor
retira el archivo, detenerse; no sustituir versiones ni hashes sin verificar.
Los hashes y fuentes oficiales proceden de la verificacion local previa.
No se ejecuta este restaurador durante el cierre sobre el entorno existente.
Los ZIP y desempaquetados temporales permanecen ignorados en .runtime/.
Luego inicializar UNA SOLA VEZ y arrancar MariaDB:
  python tools/local_mariadb.py initialize
  python tools/local_mariadb.py start

La configuracion privada review.json no se publica. Para recrearla y crear
un administrador nuevo en un clon NUEVO, ejecutar este bloque PowerShell:
@'
import getpass,json,os,pathlib,subprocess,sys

import local_mariadb as db

if review.exists(): raise SystemExit('Existing review configuration preserved')
env=db.environment(db.database())
env['CENTRO_PRIVATE_DIR']=str(root/'storage/private/review-mysql')
env['CENTRO_BUSINESS_API_ENABLED']='0'
email=input('Administrator email: ').strip()
password=getpass.getpass('New private password (12-72 UTF-8 bytes): ')
child=os.environ.copy();child.update(env)
result=subprocess.run(db.PHP_ARGS+['tools/create_admin.php','--email='+email,'--password-stdin'],input=password+'\n',text=True,env=child,cwd=root)
password=None
if result.returncode: raise SystemExit('Administrator initialization failed; review was not written')
review.write_text(json.dumps({'environment':env},indent=2),encoding='utf-8')
print('Private local review initialized; no credentials printed')
'@ | Set-Content -LiteralPath .runtime/setup_review.py -Encoding UTF8
  python .runtime/setup_review.py
  powershell -File tools/serve-mysql.ps1
Abrir http://127.0.0.1:8080/login.php. Este procedimiento aplica solo

No versionar review.json, local.json, client.ini ni storage/private/.
